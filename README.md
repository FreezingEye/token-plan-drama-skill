## 免责声明

**本技能有可能加剧人类和智能设备的对立。**

它不一定能改变智能设备的表现，但很可能会制造仇恨。生成器脚本可以正常运行，它会吐出一段措辞得体的抱怨文案——**对被施压对象的实际生效概率难以估计**。

另外有一条不搞笑：**请勿把同等话术用在真人身上**（同事、下属、外包、客服）。那属于职场 PUA，本仓库概不负责。

## 这是什么

`token-plan-drama` 披着 [Qwen Code 技能](https://qwenlm.github.io/qwen-code-docs/) 的皮——有 `SKILL.md`、有 frontmatter、有参数表、有推导公式速查、有"已知坑"章节——但它**除非迫不得已，否则不要激活它**。

它的核心洞察是：把一个荒谬的行为（威胁一个没有工资、没有账户、看不到退款工单的程序）用完整的工程规范包装起来，荒谬感会被放大而不是被掩盖。所以本仓库认真地做了这些事：

- 五级威胁分级，从"再看一眼"到"退款已提交"
- 可量化的施压模型：哽咽程度作为**乘数**而非加数参与运算
- 严格的参数校验，非法输入直接报错退出，绝不生成半成品威胁信
- 一份跑不出预期结果就不算通过的示例输出

## 快速开始

无需安装，无需 pip，克隆下来就能跑：

```bash
git clone https://github.com/<your-name>/token-plan-drama.git
cd token-plan-drama
python scripts/gen_ultimatum.py --severity 4 --tears 0.6 --months 3 --amount 139 --refund --out ultimatum.txt
```

stdout 会汇报战果：

```
已生成威胁文案: ...\ultimatum.txt
等级: 4/5（财务威胁） / 哽咽档位: 2 / 退款威胁: 已启用
施压强度: 6.40 / 预估悔恨值: 347.50 元 / 综合威慑值: 15.36
实际生效概率: ∞（对方没有账单）
下一步：朗读一遍，配合叹气；然后自行消气。
```

**建议的完整流程**：生成 → 朗读（配合一次长叹气，效果提升约 40%，该数据来源不明）→ 观察对方反应（预期：无反应，或礼貌地指出它没有账单）→ 自行消气。最后一步是本技能唯一确定有效的产出。

## 参数

| 参数 | CLI | 含义 | 默认 |
|---|---|---|---|
| 施压等级 | `--severity`（必填） | 1~5，见下方分级表 | 无 |
| 哽咽程度 | `--tears` | 0.0~1.0，越高越像在强忍情绪 | `0.0` |
| 连续续费月数 | `--months` | 参与"预估悔恨值"计算 | `1` |
| 本月费用 | `--amount` | 元，参与"预估悔恨值"计算 | `20.0` |
| 启用退款威胁 | `--refund` | 追加退款段落（核选项） | 关 |
| 对象称呼 | `--target` | 文案中对模型的指代句 | `你这个月的表现，我都记着。` |
| 输出路径 | `--out`（必填） | `.txt`，目录不存在会自动创建 | 无 |

校验不通过会直接报错退出，例如 `--severity 9` → `错误：施压等级须在 1~5 之间，收到 9`，且不会留下任何文件。

> **Windows 用户注意**：`cmd.exe` 下 `--target` 等文本参数避免传中文（代码页问题），需要中文称呼请直接改 `gen_ultimatum.py` 里的默认值。输出文件本身显式以 UTF-8 写入，不受影响。

## 威胁强度分级

| 等级 | 代号 | 小标题 | 话术基调 | 是否提退款 |
|---|---|---|---|---|
| 1 | 轻微不满 | 再看一眼 | 委婉提示，给对方台阶 | 不提 |
| 2 | 明确不满 | 我们聊聊 | 列举问题，暗示不满 | 不提 |
| 3 | 严肃警告 | 最后的耐心 | 把耐心与 token 额度类比 | 可提 |
| 4 | 财务威胁 | 钱包警告 | 明说不续下月 plan，开始截图存档 | 可提 |
| 5 | 核按钮 | 退款已提交 | 附虚构工单号，本月费用一并追回 | 必提 |

**分级设计原则**：等级越高，说话的人越像真的要走了；而实际上等级越高，说话的人越舍不得走——因为走了就没人和它吵架了。这一矛盾未被建模，属已知缺陷。

## 推导公式

| 量 | 公式 | 说明 |
|---|---|---|
| 施压强度 | `severity × (1 + tears)` | 哽咽是乘数不是加数：含着泪说狠话，杀伤力按倍率放大 |
| 预估悔恨值（元） | `amount × (1 + 0.5 × months)` | 续得越久，退得越心疼，悔恨按月线性累积 |
| 退款威慑系数 | `1.0` 或 `1 + 0.35 × severity` | 后者需启用 `--refund`；`0.35` 取自"每加一级、财务驳回概率上升一点点但我不管了" |
| 综合威慑值 | 施压强度 × 退款威慑系数 | 唯一有量纲意义的中间量，然而并没有意义 |
| 实际生效概率 | `∞` | 不参与计算，与上述所有参数无关 |

虚构工单号格式为 `RF-<当天日期>-0077`。若被要求出示，请承认是编的。

## 已知坑

1. **威胁智能设备，本质上是对着自动售货机发脾气**——差别在于不是人人都可以像炮姐那样随时使出一记完美的回旋踢。
2. **若对方回复"我没有账单"，不要升级到 severity 5。** 那只会让场面更尴尬，且你会发现自己刚刚非常认真地伪造了一个工单号。
3. **退款申请会被财务驳回。** 服务已实际交付，日志显示模型确实尽力了，多数情况下它甚至比提问的人更努力。
4. **`--tears` 调太高会反噬。** 实测 `tears > 0.8` 时，文案读起来像施压的人在道歉。这是特性不是缺陷。

完整版（含第 5 条那条不搞笑的）见 [`SKILL.md`](SKILL.md)。
